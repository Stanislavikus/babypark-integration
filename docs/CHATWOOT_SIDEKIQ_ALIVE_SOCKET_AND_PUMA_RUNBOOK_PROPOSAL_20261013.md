## A — ONE read-only socket-status inventory (requires fresh explicit approval)

**Why:** Check for current `CLOSE_WAIT` on the healthcheck port, with only TCP state and local/remote endpoint (addresses/ports). `CLOSE_WAIT` implies FIN/closure by peer and a local socket not yet closed; it is consistent with a stalled parser after early EOF. It is **not proof** that the particular hot GServer thread owns the socket, that the original connection came from the displayed peer, or that the EOF loop is the only cause of worker CPU. A negative result may be due to sampling timing, alternate port, IPv6, disconnected original socket, environment override or permissions.

**Port authority:** official installed `sidekiq_alive/config.rb` at version 2.5.0 defaults `SIDEKIQ_ALIVE_PORT` to integer **7433**; the actual effective worker runtime port has NOT been independently attested. This check covers only local TCP sport 7433. Empty result is INCONCLUSIVE until effective port verified by a separately approved *configuration name/path only* inspection. Do not query every port or infer process identity from the `ss` output.

**Planned single command envelope** (text for owner review; **do not execute**):
```bash
set -u
export LC_ALL=C
ss_bin=$(command -v ss || :)
case "$ss_bin" in /usr/bin/ss|/usr/sbin/ss|/bin/ss|/sbin/ss) ;; *) printf 'HALT_SS_PATH\n'; exit 2 ;; esac
utc_start=$(/usr/bin/date -u +%FT%TZ)
/usr/bin/setpriv --reuid=65534 --regid=65534 --clear-groups --bounding-set=-all --no-new-privs \
  /usr/bin/env -i PATH=/usr/sbin:/usr/bin:/sbin:/bin LC_ALL=C \
  /usr/bin/timeout --signal=TERM --kill-after=1s 5s "$ss_bin" -Htan '( sport = :7433 )'
rc=$?
utc_end=$(/usr/bin/date -u +%FT%TZ)
printf 'UTC_START=%s UTC_END=%s EXIT=%s\n' "$utc_start" "$utc_end" "$rc"
```
