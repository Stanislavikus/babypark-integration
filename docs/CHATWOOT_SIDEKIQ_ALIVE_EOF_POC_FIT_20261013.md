### Privilege model — NOT YET PROVEN SAFE
Connected Desktop Commander actually executes as EUID 0 root on both target and rehearsal hosts (confirmed via read-only `id -u`, `id -un`); previous read-only telemetry was root-executed, NOT non-root. Chatwoot kernel allows unprivileged user namespaces (`unprivileged_userns_clone=1`, namespace quotas >0), and `unshare`, `setpriv` are installed, but this is NOT evidence a non-root network namespace succeeds in practice. **No `unshare`, `setpriv` privilege-drop, namespace, detached process, test socket or experiment was run** in this preflight. A standalone `unshare -n` often requires CAP_SYS_ADMIN. We do not silently invoke it as root. Safest target-host variant would prove the controller launches test as isolated UID 65534 with empty environment and no privilege retention, and then user-namespace followed by network namespace inside that non-root context; if that non-mutating inspection cannot prove feasibility, a separately authorized ephemeral feasibility test (not the GServer/Puma experiment) is necessary. Failure => HALT and choose rehearsal host, not root-run fallback.

### Resource, responsiveness and stopping criteria
At most **two** run windows: GServer and Puma, each outer wall <=8 seconds, CPU rlimit <=2 CPU seconds per spawned synthetic process, virtual address <=512 MiB per process, nice +19, scratch no durable data. Treat `RLIMIT_AS` as virtual-address constraint **not a true aggregate RSS cap**; use an isolated delegated memory cgroup only if safe, separately approved and demonstrably not affecting the host cgroup hierarchy. Enforce inherited limits on children; kill ONLY tracked synthetic process group on timeout, verify no survivors, never signal the existing Worker or Web service. If Puma cannot run under those memory limits, mark PARTIAL/HALT; do not raise limits automatically. No cron/background recurrence.
Before each run check numeric MemAvailable >=1 GiB; CPU pressure `some avg10` <=5%; Chatwoot Web/Worker units ActiveState=active and MainPIDs stable; abort if counters inaccessible. During test, if numeric MemAvailable drops below 1GiB or PSI cpu.some avg10 exceeds 5% or Web unit changes state/identity, stop ONLY the isolated synthetic group. Direct Web latency measurement requires a separate explicit approval for a bounded health endpoint probe; without that consent **no claim that Web latency was tested** and no requests to live Chatwoot. Collect exact UTC RFC3339 start/end timestamp per candidate, including aborted attempts, with test-only CPU/RSS/exit-code aggregates and a banner identifying them as **synthetic experiment**, not customer traffic or production baselines. Do not overlap or reuse these timestamps as natural baseline data. Host loopback access not sufficient; listener must be in standalone network namespace without host routes. Abort if `ip link set lo up` requires elevated capability outside isolated namespace.
If synthetic CPU or process lifecycle limits cannot be independently demonstrated **before** any potentially looping request, HALT.
