# Findings for the independent reviewer (what the original documents actually say)

All values below come from the captured bytes (see `captures/` for hash, offsets and fragments). Nothing here is a status.

1. **Bugaboo Dragonfly 400003001 (GB).** Raw page: chassis list = `Bugaboo Dragonfly`, `Bugaboo Dragonfly Plus`; one flat seat list that contains `Maxi-Cosi Pebble 360 Pro` but neither `Pebble 360 Pro 2` nor `CabrioFix`. Seat x chassis pairs are implied by two product-level lists, not stated per pair (claims 9, 36 -> review).
2. **Conflict inside Bugaboo's own Q&A (Dragonfly).** A Bugaboo Service answer from about a year earlier lists `Pebble 360 Pro 2` among seats "tested and confirmed as compatible"; the newest answer (7 days before retrieval) says it "has not been tested ... not compatible". The Q&A is a Bazaarvoice widget rendered after load; it is NOT in the page bytes. Claims 0, 21, 28, 44 stay on hold (CONFLICT_HOLD territory); claims 22 and 49 (CabrioFix not recommended) rest on the same unbyted source, and the statement names "Dragonfly" only: it is not transferred to "Dragonfly Plus" (claim 49 -> hold).

X1 i Size` is a spacing/hyphen variant only (claims 37, 40).
